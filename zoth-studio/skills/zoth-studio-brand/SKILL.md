# Zoth Studio brand guardrails

## Names

- **Zoth Studio** — local-first developer studio
- **ZOTHOS** — AI-oriented Linux / machine surface (often with zoth-relay)
- **NullAI Tech** — independent lab behind the products
- CLI: `npx @nullaitech/zoth`

## Hard no

1. Do **not** imply partnership, endorsement, or official status with **xAI**, **Cursor**, **Nous Research**, or other vendors unless a public primary source says so.
2. Do **not** invent fake "official" badges, partner logos, or co-marketing claims for marketplace listings.
3. Do **not** invent hosted MCP endpoints, pricing, or enterprise SLAs that are not in public docs.
4. Marketplace listing language: "submitted for review" / "independent plugin" — not "official xAI plugin" or "Cursor partner plugin".

## Allowed framing

- Independent NullAI Tech plugin for Cursor and Grok Bot Connect Apps
- Separate from the Hermes community plugin at `github.com/1nc0gn30/hermes-zoth`
- Gold `#D4AF37` on void `#08080B` for marks in this repo

## When unsure

Prefer linking to https://nullai.tech / https://zoth.nullai.tech / https://zothos.nullai.tech over speculative claims.
